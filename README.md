# FamilienFinanzen

A professional Python desktop application skeleton built with Python 3.13 and PySide6.

## Project structure

- `app/`
  - `ui/`
  - `database/`
  - `models/`
  - `services/`
  - `importers/`
  - `reports/`
  - `settings/`
  - `utils/`
- `config/`
- `data/`
- `docs/`
- `resources/`
- `tests/`

## Setup

```bash
python3.13 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
