# Architecture

This document describes the high-level architecture for FamilienFinanzen.

## Layers

- `app/ui/`: application user interface components
- `app/database/`: persistence and storage integration
- `app/models/`: domain models and data structures
- `app/services/`: business services and orchestration
- `app/importers/`: data import adapters and parsers
- `app/reports/`: report generation and export
- `app/settings/`: configuration and application settings
- `app/utils/`: shared utilities and helpers
